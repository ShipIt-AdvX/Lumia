# Lumia Demo 脚本（约 3–4 分钟）

## 准备

```bash
cd lumia
./scripts/run-desktop.sh
```

打开桌面主控（托盘常驻）。备用网页：http://127.0.0.1:8787/  
桌上伙伴：http://127.0.0.1:8787/pet · 成就墙：http://127.0.0.1:8787/wall  

设置里把「久坐阈值」临时改成 `1`，「喝水间隔」改成 `1`，角色选 `jiege`，方便现场触发。

## 话术顺序

1. **灵感盒**  
   「灵感来了——按这颗没有屏幕的盒子（或主控输入演示）。正在做的 Focus 不会被抢走。」  
   展示清单出现 AI 整理项。

2. **睡点静默（可选口述 + 改系统时间/就寝点）**  
   「如果已经是睡觉时间，整理照做，但不会弹窗吵你。」

3. **催睡升级链（重点）**  
   触发睡觉 → **soft** 系统通知 →「延后」→ 再触发 → **侧边杰哥**「再不睡觉就让我康康」→ 再延后 → **全屏杰哥**。说明角色可换。

4. **久坐**  
   点「模拟坐下」或压真实传感 → 等到阈值 → 同套升级引擎 + 椅拉伸（simulate）。  

5. **喝水 / 吃饭**  
   Demo 按钮各触发一次。

6. **用屏**  
   切换 Cursor / 浏览器，主控里 coding / other 分钟数变化。

7. **成就墙**  
   打开 `/wall`，投屏：「今天做成的事 + 用屏 + 一句收束。」

8. **收束**  
   「脑在电脑，身体边界在桌上；清闲椅能联动时一起动，不能联也至少把人请离键盘。」

## 兜底

- 灵感盒 Wi‑Fi 挂：主界面文本捕获。  
- 椅无不动：`chair_mode=simulate` 已够叙事；继电器现场再接。  
- DeepSeek/讯飞无 Key：本地启发式照样跑通闭环。
